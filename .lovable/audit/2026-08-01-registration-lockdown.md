## 2) إغلاق التسجيل العام
- `/register` بدعوة فقط: بدون `invite` صالح لا يُعرض أي نموذج (تم اختباره: عدد النماذج = 0).
- البريد يأتي من سجل الدعوة (`tenant_invitations` عبر بصمة SHA-256) ويُعرض مُقنّعًا فقط
  (`te***@example.com`)؛ المتصفح لا يستطيع تمرير بريد آخر.
- التسجيل الذاتي في المصادقة مُعطّل تمامًا: نداء `POST /auth/v1/signup` من المتصفح يرجع
  `422 signup_disabled`.
- إنشاء الحساب يتم في الخادم عبر واجهة الإدارة (Admin API) بعد التحقق من الدعوة، وحدود
  المعدل قائمة (5/ساعة لكل IP و3/ساعة لكل بريد).
- الروابط المنتهية والملغاة تُرفض: `expired` و`revoked` → لا نموذج ولا حساب.

## 3) إنشاء المستخدم بواسطة المسؤول

  العضوية داخل مساحة العمل + الأدوار، مع فرض سياسة كلمة المرور نفسها.

## 4) وقف تكاثر المساحات الشخصية
- `ensure_personal_tenant()` صارت للقراءة فقط (تُرجع المساحة الشخصية القائمة أو لا شيء).
- سُحبت صلاحية التنفيذ من `anon` و`authenticated` و`PUBLIC`
  (تم اختباره بحساب موقّع فعليًا: `403 permission denied for function ensure_personal_tenant`).
- الواجهة لم تعد تستدعيها عند الدخول أو في `/select-account` و`/me`.
- كل إنشاء كيان جديد يُسجَّل تلقائيًا في `audit_log` بواسطة `trg_log_tenant_creation`
  (المنشئ + المصدر: دعوة / إجراء إداري / مساحة شخصية).

## 5) كلمات المرور

  والمتسلسلة، مطبّقة على: التسجيل بدعوة، إنشاء المستخدم إداريًا، وإلزام تغيير كلمة المرور.
- اختبار فعلي: `password123` مرفوضة برسالة واضحة، و`Zq7#tRv9!mLp` نجحت.
- حساب مدير النظام مُعلَّم `must_change_password = true` (لم تُقرأ كلمة المرور الحالية ولم تُغيَّر).

## 6) اختبار العزل بأدوار فعلية
كيانان اختباريان (A/B) وأربعة مستخدمين (محاسب + مشرف لكل كيان)، مع مشروع ومشرف وحركة عهدة
وطلب في كل كيان:

| الاختبار | النتيجة |
| --- | --- |
| قراءة بيانات الكيان نفسه (محاسب) | 1 سجل ✅ |
| قراءة مشاريع/عهد/طلبات/مشرفي الكيان الآخر | 0 سجل لكل الأدوار ✅ |
| `activate_account` لكيان بلا عضوية | مرفوض `NO_ACTIVE_MEMBERSHIP` ✅ |
| `ensure_personal_tenant` من مستخدم موقّع | مرفوض 403 ✅ |
| قراءة الجداول من زائر (anon) | 401 ✅ |

تم أرشفة كل بيانات الاختبار بعد الانتهاء (حسابات الاختبار محذوفة، كياناتها مؤرشفة مع
الحفاظ على سجل العمليات).
