# إغلاق وحدة «توزيع الأعمال والموظفون داخل إدارة المنصة»

التاريخ: 04/08/2026 — الاختبارات فعلية عبر جلسة مدير النظام (REST/RPC) وPlaywright.

## النطاق المنفَّذ
- التوزيع الآلي العادل بين جميع الموظفين المؤهلين المتاحين (بدون تخصص/أقسام).
- حالة العمل منفصلة عن حالة الحساب: available / busy / away / leave / off.
- الإجازات: تسجيل، تفعيل تلقائي لحالة «إجازة»، وإلغاء يعيد الحالة السابقة.
- القائمة المشتركة: إدخال آلي (إعلانات المراجعة، البلاغات، طلبات التوثيق)، استلام ذري، تحويل، إعادة للقائمة بسبب إلزامي.
- الحد التشغيلي (capacity) يمنع الإسناد الآلي واليدوي عند الامتلاء.
- صفحة الموظف `/admin/my-work` متاحة لكل موظفي الإدارة، ولوحة `/admin/workforce` مقيَّدة بصلاحية `workforce.manage`.
- سجل تدقيق لكل عملية (إسناد، تحويل، إعادة، إجازة، تغيير حالة/حد).

## نتائج الاختبارات
| الاختبار | النتيجة |
|---|---|
| إسناد آلي عند الإدخال | ✅ عنصران أُسندا، والثالث بقي في القائمة المشتركة عند الامتلاء |
| الحد التشغيلي (استلام يدوي) | ✅ `capacity_reached` |
| إنجاز عمل يحرّر السعة ثم الاستلام | ✅ نجح |
| إعادة للقائمة بدون سبب | ✅ `reason_required` |
| الاستلام أثناء الإجازة | ✅ `staff_on_leave` |
| التوزيع الآلي وكل الموظفين في إجازة | ✅ 0 إسناد |
| عدالة التوزيع (4 أعمال / موظفان) | ✅ 2 و 2 |
| استعادة الحالة بعد إلغاء الإجازة | ✅ عودة إلى «متاح» |
| الصلاحيات للزائر (anon) على دوال القوى العاملة | ✅ 401 permission denied |
| الواجهات 390px و 1280px | ✅ بلا تجاوز أفقي وبلا أخطاء Console |

## ملاحظات
- بيانات الاختبار حُذفت، وأعيدت حالات الموظفين إلى «موقوف عن الاستلام» مع حد 10.
- تحذيرات المدقّق (306) هي خط الأساس السابق ولم تتغير بهذه الدفعة.
- لم يُنفَّذ (بأمر صريح): الأقسام المتخصصة، الرواتب، الحضور والانصراف، النشر.
