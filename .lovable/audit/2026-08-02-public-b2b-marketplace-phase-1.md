## 1) ملف المنشأة القابل للتعديل
- `src/routes/dashboard/business.tsx`: تعديل البيانات (الاسم عربي/إنجليزي، العنوان التعريفي، النبذة، الشعار، المدينة/المنطقة، التصنيفات، بيانات التواصل مع خيار الإظهار للعامة، نشر الملف) + تبويب معاينة لما يراه الزائر.
- منع تغيير التوثيق ذاتياً: الحالة `verification_status` تُحدَّد بواسطة إدارة السوق فقط، ومحروسة بمشغّل `mkt_guard_business_verification` على مستوى قاعدة البيانات، وليس بالواجهة فقط.
- طلب التوثيق يُقدَّم عبر `mkt_verification_requests` + مستندات في مجلد خاص داخل `mkt-media`، مع سجل زمني `mkt_verification_events`.
- سجل تدقيق: كل قرار/تغيير حالة يُسجَّل في سجل الأحداث وسجل العمليات العام.

## 2) لوحة إدارة الإعلانات
- `src/routes/admin/listings.tsx` مع بوابة `AdminShell` (لا يدخلها إلا مخوّلو المنصة عبر `mkt_is_platform_admin`).
- القرارات عبر `mkt_review_listing`: **اعتماد / رفض بسبب / إيقاف / إعادة للتعديل**، والسبب إلزامي لغير الاعتماد.
- بحث بالعنوان وفلاتر: الحالة، المنشأة، التصنيف، المدينة. عرض كامل يضم الوصف والصور والسجل الزمني `mkt_listing_status_history`.
- توحيد حالات الإعلان مع قاعدة البيانات: `draft / pending / published / rejected / suspended / expired / archived / deleted` (أُزيل استخدام `pending_review` من الواجهة).

## 3) إدارة توثيق المنشآت
- `src/routes/admin/verifications.tsx`: عرض الطلبات وفلترتها، فتح المستندات بروابط موقّعة قصيرة المدة (300 ثانية)، والقرارات: اعتماد / رفض بسبب / طلب استكمال عبر `mkt_review_verification`.
- منع النشر للمنشآت غير الموثقة: `ListingForm` يمنع الإرسال للمراجعة ويسمح بحفظ المسودة فقط، مع فرض القاعدة في قاعدة البيانات (`mkt_is_verified_business` + مشغّل حالة الإعلان).

## 4) اختبارات تسجيل الدخول والعودة للإجراء

- `/dashboard/my-ads` للزائر ← تحويل إلى صفحة الدخول ✅

## 5) اختبارات الأمان وRLS
- جميع جداول `mkt_*` (16 جدولاً) عليها RLS مفعّلة وسياسات فعلية — لا يوجد جدول بلا سياسات.
- `/admin/*` للزائر: تُعرض رسالة «لا تملك صلاحية الدخول» ولا تُقرأ أي بيانات ✅
- المسودات وبيانات المنشآت غير المنشورة غير مقروءة للعامة (سياسة النشر + `mkt_listing_is_public`).
- ملفات التوثيق ومرفقات الطلبات في bucket خاص، والوصول بروابط موقّعة قصيرة المدة فقط.
- تشديد إضافي: سُحبت صلاحية التنفيذ العام عن 10 دوال مشغّلات/حماية داخلية في السوق. عدد ملاحظات المدقّق: 130 ← 120 (المتبقي ملاحظات قديمة سابقة لهذه المرحلة).
